# Python Fundamentals Practice

This repository contains my Python practice code and assignment questions. I have created these programs to practice the basic concepts of Python that I learned in class.

## Topics Covered

- Variables and comments
- Print and input
- Type casting
- Conditional statements (if, if-else, if-elif)
- Loops (for, while, break, continue, else)
- Functions and scope of variables
- Operators (arithmetic, comparison, logical, assignment)
- Lists, tuples, sets, and dictionaries
- Strings, indexing, and slicing

## Practice Questions

### Question 1: Bill Splitter
A program that calculates the tip, total bill, and amount each person has to pay.

### Question 2: Password Strength Checker
A program that checks whether a password is strong, moderate, or weak.

### Question 3: Guessing Game
A number guessing game where the user gets 5 attempts to guess the correct number.

### Question 4: String Slicer & Manipulator
A program that displays the initials, uppercase name, and reversed name.

### Question 5: Global vs. Local Bank
A program that uses deposit and withdrawal functions to update a bank balance.

### Question 6: Unique Character Counter
A program that finds and counts the unique characters in a sentence, ignoring spaces.

### Question 7: Student Grading System
A program that stores the marks of 5 students and assigns grades according to their marks.
